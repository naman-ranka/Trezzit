Claude

  1. Open Settings, then Connectors.
  2. Find Trezzit and select Connect, or add a custom connector with the server URL below.
  3. Sign in to Trezzit and allow access.

ChatGPT

  1. Open the apps directory and search for Trezzit.
  2. Until it’s listed, add it in developer mode with the server URL below.
  3. Connect, sign in to Trezzit and allow access.
