Connect in a minute.

  1. Need an account? Sign up free
  2. In Claude, open Settings → Connectors.
  3. Choose Add custom connector, name it Trezzit and paste the server URL.
  4. Sign in to Trezzit, check what Claude is asking for, and select Allow access.
  5. In a chat, turn Trezzit on from the tools menu and ask away.
  1. Need an account? Sign up free
  2. In ChatGPT, turn on developer mode and add a connector with the server URL.
  3. Select Connect, sign in to Trezzit, and select Allow access.
  4. Mention Trezzit in a chat, or pick it from the tools menu, and ask.
  1. Need an account? Sign up free
  2. Any app that supports remote MCP servers with OAuth sign-in can connect with the server URL.
  3. In Claude Code, for example:
claude mcp add --transport http trezzit https://api.trezzit.com/api/mcp

Custom connectors may need a paid plan in the AI app.
