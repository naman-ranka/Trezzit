https://api.trezzit.com/api/mcp

Connect in a minute.

  1. In Claude, open Settings → Connectors.
  2. Add custom connector named Trezzit; paste the server URL.
  3. Sign in and select Allow access.
  4. Turn on Trezzit from a chat’s tools menu.
  1. In ChatGPT, add Trezzit as a custom app (Developer mode) and paste the server URL.
  2. Select Connect, sign in to Trezzit, and select Allow access.
  3. Mention Trezzit in a chat, or pick it from the tools menu, and ask.

Photo scanning needs code execution turned on.

  1. Any app that supports remote MCP servers with OAuth sign-in can connect with the server URL.
  2. In Claude Code, for example:
claude mcp add --transport http trezzit https://api.trezzit.com/api/mcp
